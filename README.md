# Kevin Ye

I build mobile apps, AI tools, and things for my family. Based in Vancouver, with 10 years in software engineering and a background in Android.

## Currently building

**[PiBox](https://github.com/dev32-io/PiBox)** — My take on a better coding-agent environment, built on [Pi](https://github.com/badlogic/pi-mono).

- Multi-agent workflows that take a reviewed plan through implementation, code review, and end-to-end verification.
- An orchestrator that coordinates subagents using a scratch plan and working ledger to track decisions, progress, and what remains to be verified.
- Live architecture diagrams, browser mockups, and a visual workflow board alongside the terminal.

**[Sentient](https://github.com/dev32-io/sentient)** — A voice and text assistant I run for my family on a Mac mini.

- Local speech recognition and synthesis with interruptible conversations.
- Custom-built **DeepMemory**: text embeddings and vector-based semantic search recall relevant personal and household context; a nightly “dreaming” process distills conversations and reconciles lasting memories.
- A native TypeScript agent runtime connecting models to web research, calendars, and household tools, with permissions and confirmation for sensitive actions.
- A web app in daily household use; native Android and iOS clients in development with a shared Kotlin Multiplatform layer.

Mostly Kotlin, TypeScript, and Python. Interested in agents that do useful work and software that holds up beyond the demo.
